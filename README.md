How many tabs do you have open? **137.**

Not 100, not 500, not a round number picked to shock. 137 is the honest
count of a browser that has become a second memory: the "read later" tabs
that never get read, the research rabbit holes left open for weeks, the
half-finished pages kept just in case. Far above what anyone would guess,
still a count a real person can have open right now — Chrome holds it,
tab groups hold it, and nobody invents 137 when they want to impress.

Three counts were weighed before this one: **1** (the monk's single tab —
sharp, but too ordinary to surprise), **87** (a believable hoard, but
where heavy users already live), and **137** (the farthest honest count:
surprising, believable, and lived-in).

## How it works

`main.ts` writes exactly `137` — digits only, no words, no punctuation,
no newline — to `/output/entry.txt`. It refuses to write anything that is
not 1–5 digits, then reads the file back and proves it holds exactly that.
No network, no secrets, no dependencies — just Node.

```sh
node main.ts
```
